# SQL 知识点覆盖审计

MySQL 8.0.18+ 核心查询、分析与数据库工程；特定小版本差异在题干中单独约定。

逐题语义映射，只有题干或作答所必需的知识点才计入；一题可对应多个实际考点；原有结果推导变式计为独立练习，不当作新知识点。实战及工程挑战不计入三道客观题门槛。

这是一份明确范围的核心清单，不宣称覆盖所有 SQL 标准、数据库方言或内部实现。空间/GIS、向量检索、插件、分布式共识实现、专业 DBA 全部调优参数等未列入。题量达标不证明技能已经掌握。

审计前：400 题，111 个考点中 59 个不足三题，其中 16 个为零题。
补齐后：519 题，111 个考点全部至少三题；新增 119 题均含讲解。
