随手查 · 知识工具箱

高中知识先用起来；导数、积分和矩阵在需要时补。

高中 · 列表与分类

集合与事件

集合就是把符合要求的东西装进同一份名单。∈ 表示“在名单里”；∅ 表示空名单。A∪B 收集至少在一份名单里的元素；A∩B 只保留同时在两份名单里的元素。Aᶜ 要相对于事先选定的全集 Ω 来取。

Ω={1,2,3,4,5,6}，A={2,4,6}，B={4,5,6}。A∪B={2,4,5,6}；A∩B={4,6}；Aᶜ={1,3,5}。∪ 像字母 U，但字母 U 本身不表示交集。
高中 · 四则运算

分数、比例与百分数

分数先读分母：我们在什么范围里数？再读分子：其中符合要求的有几个？只有有限个基本结果等可能时，事件概率才能直接用“个数之比”。

全班 10 人，4 人戴眼镜，随机等可能选一人：概率 4/10=0.4=40%。若改为只在 5 名女生中选，其中 3 人戴眼镜，比例就是 3/5；参照范围已经换了。
高中 · 乘法与计数

乘法、指数与组合

a³=a×a×a。先给每一步列选择数，再按路径相乘；概率相乘的一般规则用条件概率，独立时才可直接乘各自的原概率。n! 表示从 n 一直乘到 1，规定 0!=1。

两次独立公平抛硬币，指定“正、反”的概率是 1/2×1/2=1/4。恰好一次正面包含“正反”和“反正”，两条互斥路径相加为 1/2。
高中 · y=f(x)

函数、坐标与面积

函数是一条输入到输出的规则。横轴放输入 x，纵轴放输出 f(x)，点 (x,f(x)) 记录一次对应。曲线的高度和曲线下的面积是不同的量。

f(x)=2x：输入 0、1、2，输出 0、2、4。若把 x 从 1 改到 2，图上的点从 (1,2) 移到 (2,4)。宽 0.1、高 2 的长方形面积为 0.2。
高中 · 平均数

平均、加权与求和

普通平均是总和除以个数。加权平均让不同数占不同份额：先各自乘份额，再相加。Σ（或排版为 ∑）只是“把这些项加起来”的简写。下标 i 是第几项，不是额外相乘。

数据 2、4、6 的平均=(2+4+6)/3=4。若数值 0 出现的概率为 3/4，数值 4 出现的概率为 1/4，加权平均=0×3/4+4×1/4=1。
高中 · 代数

平方、根号与单位

偏差是“数值−中心”。偏差直接相加会正负抵消；平方后都不小于 0。√a 表示平方等于 a 的非负数。平方让单位也平方，开根号可以把单位还原。

1 秒和 3 秒的中心是 2 秒。偏差为 −1、1 秒，平均偏差为 0；平方后平均为 (1+1)/2=1 秒²，开根号得到 1 秒。
高中延伸 · 先看逆运算

对数与指数

若 2³=8，就有 log₂8=3。对数问的是“底数要乘几次”。ln 是以 e≈2.71828 为底的对数，exp(x)=eˣ。正数 a、b 满足 ln(ab)=ln a+ln b；ln 递增，因此取 ln 不改变正数的大小次序。

ln(1)=0，ln(0.5)≈−0.693，−ln(0.5)≈0.693；−ln(0.25)≈1.386。预测真实结果的概率越小，负对数惩罚越大。ln 的输入必须大于 0。
新工具 · 本节用到才补

导数：变化率

先算平均变化率：[f(w+h)−f(w)]/h，分子是输出变化，分母是输入变化。当 h 越来越接近 0，若这个比值趋近一个固定数，就把它叫 f 在 w 处的导数。它表示当前位置附近的斜率。

f(w)=w²。展开 (w+h)²=w²+2wh+h²，减掉 w² 再除以 h，得 2w+h。让 h 趋近 0，得到导数 2w。在 w=3 处斜率为 6；w 小增 0.01，f 约增 0.06。
新工具 · 面积的记法

积分：把小块累加

∫ₐᵇ f(x)dx 表示从 a 到 b 把函数下的小条面积累起来。a、b 是左右边界，f(x) 是高度，dx 提醒我们小条沿 x 方向切得很细。这里用于非负密度；严格的极限定义需要微积分。

在 [0,0.5] 上高度恒为 2，面积就是 2×0.5=1。若 f(x)=2x，在 [0,0.5] 下方是直角三角形，面积=底 0.5×高 1÷2=0.25，不需要先会积分运算。
新工具 · 数字列表与表格

向量与矩阵

向量先看成有顺序的一列数；矩阵是一张按行列排列的数表。形状 (2,3) 表示 2 行、3 列。矩阵乘向量时，每一行与向量对应相乘后相加。ᵀ 表示转置，也就是把行和列互换。

W=[[1,2],[3,4]] 的形状为 (2,2)，h=[10,20] 长度为 2。Wh=[1×10+2×20,3×10+4×20]=[50,110]。先检查每一行的长度能否与输入对齐。
新工具 · 一次只改一个数

偏导、梯度与更新

模型有多个参数时，先固定其他参数，只改一个参数，得到偏导；把各参数的偏导按顺序放在一起就是梯度。链式法则把“中间量受参数影响多少”与“结果受中间量影响多少”相乘。梯度下降：新参数=旧参数−学习率×梯度。

令 z=2w，J=z²。J 对 z 的导数是 2z，z 对 w 的导数是 2，所以 J 对 w 的导数是 4z=8w。w=1 时梯度为 8，学习率 0.1，更新得 w=0.2。步长过大可能让损失上升。
03 / 从样本学习参数 第 66 节

MLE伯努利示例

这一节只抓住一件事：完整推导伯努利 MLE，并连接二元交叉熵和 sigmoid 梯度。

本节现场CASE 66

成功率这个旋钮，究竟该拧到哪儿？

还是 [1,1,0]，你把 p 从 0 慢慢拧到 1。太小解释不了两个成功，太大又解释不了最后的失败。

轮到你

极大似然会把旋钮停在哪儿？

先选一个。这里不计分；选完会告诉你，直觉在哪一步拐了弯。

想先自己推一遍？稍后看提示

p²(1−p) 在 p=2/3 处最大。更一般地，独立同成功率的伯努利样本，MLE 就是成功次数除以总次数。接下来把这个寻找过程接到损失和梯度上。

01 / 把现场翻译成数学

先用一组小数字，摆好问题。

固定 [1,1,0]，有两次成功、一次失败，所以似然 L(p)=p²(1−p)。p=0 或 1 都给这份数据零概率；最优点在 2/3，和成功比例相同。

观察到多少成功，就让模型的成功率尽量接近这个比例。这个看起来朴素的答案，可以从似然一步一步算出来，也直接连接分类损失。

02 / 把字母读懂

先认人，再看公式。

先固定

当前训练或观测数据；真实标签 y 不是待调参数。

在改变

模型参数 θ（例如 w、b、p）；预测随参数改变。

计算结果

似然、后验、损失或梯度；它们的作用各不相同。

这一节会遇到的符号 · 点开对照

L / J
似然常记 L；本手册的训练损失常记 J，勿混淆。
ln / exp

∂ / ∇ / η
只改一个参数的导数 / 各偏导组成的梯度 / 学习率。
p / q
信息论中常指真实分布 / 模型分布；两者都不是标签。

字母的含义取决于本节定义；同一个字母在不同场景可能有不同用法。

03 / 连起来想

每一步，都有来由。

  1. 01

    固定 [1,1,0]，写出似然 L(p)=p²(1−p)，0<p<1。

  2. 02

    取自然对数：ln L=ln(p²)+ln(1−p)=2 ln p+ln(1−p)。求最小负对数损失 J=−2 ln p−ln(1−p)。

  3. 03

    用导数规则 d(ln p)/dp=1/p；对 ln(1−p) 还要乘里面的导数 −1。因此 J′(p)=−2/p+1/(1−p)。

  4. 04

    通分到 p(1−p)：J′=[−2(1−p)+p]/[p(1−p)]=(3p−2)/[p(1−p)]。分母为正，p<2/3 时为负，p>2/3 时为正。

  5. 05

    损失先降后升，所以最小点 p=2/3。一般 n 次中成功 k 次时同样得到 p̂=k/n；全成功或全失败时最优值在边界。

  6. 06

    若单样本 y 只取 0/1，损失为 −[y ln p+(1−y)ln(1−p)]。把 p 设为 sigmoid(z)=1/(1+e^(−z))，链式法则会得到损失对 z 的梯度 p−y，见下方训练例子。

04 / 再算一次

把数字带回去。

10 次中成功 7 次，p̂=0.7。再看单样本：x=2、y=1，当前 z=0，p=0.5，则 dJ/dw=(0.5−1)×2=−1。学习率 0.1 时 w 增加 0.1，推动 z 与正类概率上升。这就是概率损失如何接到反向传播。

验证 / 把手算交给程序

Python · 从概率到一次分类训练

下面是可直接运行的完整 Python 例子，只使用 Python 自带功能。

Python 3
import math

x, y = 2.0, 1.0
w, b = 0.0, 0.0
rate = 0.1
z = w * x + b
p = 1 / (1 + math.exp(-z))
loss = -math.log(p)
grad_z = p - y
grad_w = grad_z * x
grad_b = grad_z
print("更新前:", p, loss)
w = w - rate * grad_w
b = b - rate * grad_b
new_z = w * x + b
new_p = 1 / (1 + math.exp(-new_z))
print("新参数:", w, b)
print("更新后:", new_p, -math.log(new_p))

这是单个正类样本 y=1，因此损失简化为 −ln p。所有变量都是单个数。math.exp 替我们算指数，math.log 替我们算自然对数；分类概率由 sigmoid 计算。输出：更新前约 0.5、0.693；新参数 0.1、0.05；更新后约 0.562、0.576。它与本节的通用交叉熵公式一致。

这里停一下。

分类标签与模型概率必须配对。极端概率的 log 有数值风险，实际训练优先使用从 logits 稳定计算的交叉熵实现。

理解以后，再接到机器学习

链式法则把概率损失传回参数。用 x=2、y=1、w=b=0 起步，z=0、p=0.5、损失约 0.693；梯度为 w 的 −1 和 b 的 −0.5。学习率 0.1 更新后 w=0.1、b=0.05，z=0.25、p≈0.562、损失约 0.576。输入和标签固定，改变的是参数以及随之改变的预测。
