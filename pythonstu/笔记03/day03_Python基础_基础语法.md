## 3.【熟悉】Python注释与快捷键



### 3.1 注释的作用

首先强调一件事：Python代码 => Python解析器 => 机器语言，但是注释经过了Python的解释器并不会解析与执行。因为其主要就是进行代码的注释。

注释作用：提高代码的阅读性

![image-20210306143714495](assets/image-20210306143714495.png)

在我们编写Python程序时，为了了提高程序的可读性，强烈建议大家为核心代码添加注释信息。

### 3.2 Python注释的基本语法

#### ☆ 单行注释

单行注释，以"#"(Shift + 3)号开头，只能注释一行内容

```python
# 注释内容
```

示例代码：

第一种：代码行的上面

```python
# 这是单行注释 (注释可以放置到代码的上面)
print("Hello World")

```

第二种：放在代码的后面(代码后面保留2个空格)

```python
print("Hello World") # 这是单行注释 (注释也可以放置到代码的后面  一般不建议)

```

#### ☆ 多行注释

多行注释：可以同时注释多行代码或程序，常用于代码块的注释

基本语法：

```python
"""
注释内容
第一行
第二行
第三行
"""
```

或

```
'''
注释内容
第一行
第二行
第三行
'''
```



课上演示：

```python
# 演示注释
# 这是一个单行注释
# 格式化代码: ctrl + alt + l
# 快速复制一行并粘贴到下一行: ctrl + d
# 快速添加注释:  ctrl + /
print('Hello World')  # 注意：在代码语法中,所有的涉及到的符号, 都是英文格式的符号
"""
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释

"""

'''
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释
    我是一个多行注释

'''
```

## 4 【掌握】Python中的变量

### 4.1 引入变量的概念

那什么是变量呢？

① 变量是存储数据的容器

② 变量在程序运行过程中是可以发生改变的量 

③ 变量存储的数据是临时的

### 4.2 变量的定义

基本语法：

```python
变量名称 = 变量的值
注：等号的两边都要保留一个空格，其实Python中建议符号的两边尽量都要保留一个空格
```

> 说明：在Python程序中，这个等号和日常生活中的等号不太一样，其有一个专业名词：赋值运算符，其读法：要从右向左读，把变量的值通过 = 赋值给左边的变量。

### 4.3 变量的命名规则

标识符命名规则是Python中定义变量名称时一种命名规范，具体如下：

① 由数字、字母、下划线(_)组成

② 不能数字开头

③ 严格区分⼤小写

④ 不能使⽤内置关键字作为变量名称

![image-20210306155908564](assets/image-20210306155908564.png)

举个栗子：

① abc、abc123、_abc、hello（合理）

② 123abc、@abc、abc-123（不合理）

③ _（下划线） => 请问这可以是一个变量名称么？答：可以

```python
for _ in range(10):
    ...
```

> 注意：在Python变量命名时，不建议使用_开头，因为其与后面要学习的私有属性想冲突

④ 变量abc和变量ABC是同一个变量么？答：不一样，这是两个完全不同的变量

⑤ 记不住Python关键字怎么办？答：借助于help()方法

```python
>>> help('keywords')
```

### 4.4 推荐变量的命名规则

① **变量命名一定要做到见名知义。**

② 大驼峰：即每个单词首字母都大写，例如： MyName 。

③ **小驼峰：第二个（含）以后的单词首字母大写，例如： myName 。**

④ **下划线：例如： my_name** 。

### 4.5 变量的定义与调用

在Python中，记住：变量一定要先定义，后使用，否则会报错。

定义：

```python
name = 'itheima'
address = '北京市顺义区京顺路99号'
```

调用：

```python
print(name)
print(address)
或
print(name, address)
```



相关的演示:

```python
# 演示变量
"""
    定义变量的格式:
        变量的名称 = 值

        指的: 将等号右侧的值 赋值给 左侧的变量

    变量的名称定义规范:
        强制规范:
            1- 变量必须是以 数字 字母 或 下划线 组成
            2- 变量不能以数字开头
            3- 变量严格区分大小写
            4- 不能使用python中关键词作为变量名称

        推荐规范:
            1- 变量命名必须是见名知意
            2- 当变量名称涉及到多个单词的时候:
                方式一: 大驼峰命名    例如: MyName
                方式二: 小驼峰命名    例如: myName
                方式三:  下划线连接   例如:  my_name


"""

# 1- 定义一个年龄的变量 值为 18
age = 18

# 2- 定义一个名字的变量  值为 张三
userName = '张三'

# 如何使用变量呢?
# 如何调用: 通过变量名称
print(age)
print(userName)
```

### 4.7 变量的数据类型

变量的定义非常的简单，但是很多小伙伴可能会想：变量除了存储这种字符类型的数据以外，还能存储其他类型的数据么？其实，在 Python中，我们为了应对不同的业务需求，也会把数据分为不同的类型，如下图所示：

![image-20210306162601034](assets/image-20210306162601034.png)

面试题：请手写出Python中的7种数据类型？

答：数值类型、布尔类型、字符串类型、列表类型、元组类型、集合类型、字典类型

今天我们只需要了解前3种即可。



问题：如何判断一个变量到底是什么类型？

答：① 使用type(变量名称)方法，返回变量的数据类型 ② isinstance(变量名称,数据类型)，只能返回True或False（真的还是假的）

#### 4.7.1 数值类型

数值类型就是我们日常生活中的数字，数字又分为两种形式：整数 与 小数（带小数点）

整数类型：int类型

小数类型：float类型

案例1：定义一个人的信息，姓名：Tom、年龄18岁  并且打印出结果

```python
# 演示 变量的数据类型
"""
    数据类型共计有 7 种:
        数值类型 :  整数类型 int   和  小数类型 float
        布尔类型 :  真 True  假 False
        以下为五大容器,用于一次性保存多个数据:
            字符串类型:  文本数据, 一般使用 引号 引起来, 可以单引号 也可以 双引号
            列表类型
            元组类型
            集合类型
            字典类型

    如何判断数据类型:
        type(变量)  返回 对应变量的数据类型
        isinstance(变量名称,数据类型)  判断对应变量是否是这个数据类型, 如果是 返回True 否则返回False
```

但是往往只有input()方法，其意义不大，我们还应该使用一个变量来临时接受用户的输入，已方便后期的操作。

```python
变量名称 = input('提示信息：')
```

案例：银行系统中的，输入密码的过程: 提示内容    请输入您的密码？  并且打印出用户输入的内容
