# day08_数据分析综合实战

## 新能源汽车销售与售后服务分析系统

---

### 一、业务背景  
随着“双碳”目标推进，新能源汽车市场快速发展。某新能源汽车品牌“绿驰汽车”在全国设有多个销售门店与服务中心，需对销售、客户、车辆及售后服务数据进行统一管理与分析，以优化营销策略、提升客户满意度、监控车辆质量。现需构建一套轻量级数据仓库，支撑日常运营分析，并通过FineBI制作可视化大屏。

---

### 二、数据库与表结构设计  
**数据库名称**：`ev_sales_analytics`  

#### 1. 客户信息表（`customers`）  
存储购车客户基本信息。  

| 字段名            | 数据类型    | 约束说明                             |
| ----------------- | ----------- | ------------------------------------ |
| customer_id       | INT         | **主键**，自增                       |
| name              | VARCHAR(50) | **非空**                             |
| gender            | CHAR(1)     | **非空**，取值 'M'（男）或 'F'（女） |
| phone             | VARCHAR(20) | **唯一**，**非空**                   |
| city              | VARCHAR(30) | **非空**                             |
| registration_date | DATE        | **非空**                             |

---

#### 2. 车辆信息表（`vehicles`）  
记录销售车辆的型号、生产信息。  

| 字段名           | 数据类型      | 约束说明                              |
| ---------------- | ------------- | ------------------------------------- |
| vin              | VARCHAR(18)   | **主键**，车辆识别码（唯一）          |
| model            | VARCHAR(30)   | **非空**（如：Model S, iX3, NIO ET7） |
| brand            | VARCHAR(20)   | **非空**，固定为 'GreenDrive'         |
| production_date  | DATE          | **非空**                              |
| battery_capacity | DECIMAL(5,1)  | **非空**，单位：kWh（如 75.0, 100.5） |
| sale_price       | DECIMAL(10,2) | **非空**，单位：万元                  |

---

#### 3. 销售记录表（`sales`）  
记录每笔车辆销售交易。  

| 字段名      | 数据类型    | 约束说明                                          |
| ----------- | ----------- | ------------------------------------------------- |
| sale_id     | INT         | **主键**，自增                                    |
| vin         | VARCHAR(18) | **外键**，引用 `vehicles(vin)`，**非空**          |
| customer_id | INT         | **外键**，引用 `customers(customer_id)`，**非空** |
| sale_date   | DATE        | **非空**                                          |
| sales_rep   | VARCHAR(30) | **非空**，销售顾问姓名                            |
| store_city  | VARCHAR(30) | **非空**，销售门店所在城市                        |

---

#### 4. 售后服务表（`service_records`）  
记录车辆售后维修/保养记录。  

| 字段名       | 数据类型     | 约束说明                                   |
| ------------ | ------------ | ------------------------------------------ |
| service_id   | INT          | **主键**，自增                             |
| vin          | VARCHAR(18)  | **外键**，引用 `vehicles(vin)`，**非空**   |
| service_date | DATE         | **非空**                                   |
| service_type | VARCHAR(20)  | **非空**，取值：'保养', '维修', '软件升级' |
| cost         | DECIMAL(8,2) | **非空**，单位：元，**默认值 0.00**        |
| description  | VARCHAR(200) | 可为空                                     |

### 四、分析需求（20个查询指标）  
1. **单表-客户**：统计各城市的客户数量，按数量降序排列。  
2. **单表-车辆**：查询所有车辆的型号、电池容量及售价，按售价从高到低排序。  
3. **单表-销售**：计算2023年每月的销售数量（按月份分组）。  
4. **单表-服务**：统计各类售后服务（保养/维修/软件升级）的总次数。  
5. **单表-服务**：找出单次维修成本最高的3条记录。  
6. **多表-客户+销售**：查询每位客户的姓名、所在城市及购车日期（需连接 `customers` 和 `sales`）。  
7. **多表-车辆+销售**：列出所有已售车辆的VIN、型号、销售日期及销售城市。  
8. **多表-销售+服务**：统计每辆车（VIN）的售后服务次数（包括0次）。  
9. **多表-客户+车辆+销售**：查询购买“NIO ET7”车型的客户姓名及所在城市。  
10. **多表-车辆+服务**：计算各车型（model）的平均维修成本（仅含维修类型）。  
11. **窗口函数-销售**：为每笔销售记录按销售日期排序，显示“当日累计销售额”（使用 `SUM() OVER()`）。  
12. **窗口函数-客户**：按客户注册日期排序，显示每位客户的“注册排名”（使用 `ROW_NUMBER()`）。  
13. **窗口函数-车辆**：对每款车型（model）按售价降序排列，显示“车型内售价排名”（使用 `RANK()`）。  
14. **窗口函数-服务**：计算每辆车（VIN）每次服务与上一次服务的间隔天数（使用 `LAG()`）。  
15. **多表+窗口函数**：统计各销售城市2023年的月度销售量，并显示“该城市历史最高月销量”（使用 `MAX() OVER(PARTITION BY ...)`）。  
16. **多表+聚合**：查询每个销售顾问（sales_rep）负责的客户数量及总销售额。  
17. **多表+条件**：找出2024年购买车辆且在3个月内进行过保养的客户姓名。  
18. **多表+分组**：按车型和城市分组，统计各城市各车型的销量。  
19. **窗口函数+条件**：对每辆车（VIN）的服务记录按日期排序，标记“是否首次服务”（使用 `ROW_NUMBER()` 判断）。
