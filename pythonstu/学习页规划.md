## 学习顺序

1. 环境从零：为什么需要解释器；Windows + VS Code 运行第一份文件；官方 Python、Anaconda、Miniconda、Conda 的关系；venv、pip 与排错。
2. 让程序开口：变量、类型、输入输出、类型转换。
3. 做出选择：运算符、布尔逻辑、分支。
4. 重复做事：while、for、range、break / continue / else。
5. 整理文字：索引切片、查找替换、拆分拼接。
6. 收纳一组数据：列表、元组、嵌套数据。
7. 给数据分类：集合、字典、拆包与推导式。
8. 把步骤变成工具：函数、返回值、作用域。
9. 函数的进阶用法：参数、拆包、lambda 与排序。
10. 把结果留下：文件模式、读取写入、with、按行处理与二进制复制。
11. Ollama 从零：软件、服务、模型、Python 客户端的分工；安装与健康检查；模型标签、量化、首次运行。
12. Ollama 管理：系统命令与会话指令；采样参数、上下文、性能日志；Modelfile 与模型目录迁移。
13. HTTP / API：BH day02 的 JSON、Apifox、chat / generate、流式与非流式、向量化、ChatBox。
14. Python 接入：SDK 安装与调用、完整历史传递、流式输出、异常分类、JSON 记录、Streamlit 会话状态。
15. 模块与项目结构：import、__main__、pathlib、配置与依赖清单。
16. 异常与测试：函数契约、输入校验、错误分类、unittest 与假客户端。
17. 迭代与数据处理：enumerate、zip、yield、分批、Counter、分组与复杂度。
18. 小工具接口：dataclass、实例状态、argparse、logging 与职责分层。
