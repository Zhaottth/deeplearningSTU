## 3.FineBI入门

### 简介

```properties
BI是什么:(Business Intelligence)商业智能,一套完整的解决方案
BI能干什么: BI能帮助企业管理者做决策

FineBI是什么: FineBI是做数据报表的工具
FineBI架构:是一款纯 B/S 端的商业智能分析服务平台；
```

### BS和CS架构

```properties
B/S架构:  Browser浏览器/Server服务器
C/S架构:  Client客户端/ Server服务器

BS和CS的区别
    BS:web页面应用   优点: 可以实现跨平台，无需提前下载,客户端零维护            缺点:个性化能力低，响应速度较慢。
    CS:桌面app应用   优点: 个性化能力强，响应速度快，安全性强                  缺点: 需要提前下载并维护,维护成本相对较高
```

## 5.创建仪表板

针对一个具体的分析业务，可以创建一个仪表板，在仪表板上可以添加很多分析组件，方便最终统一对各个分析结果进行查看。

```properties
步骤: 仪表板→ 新建文件夹 → 新建仪表板。
```

## 6.维度和指标

```properties
创建仪表板之后，即可在仪表板上添加分析组件，利用数据进行分析操作。

指标: 指标是对数据的量化，用于衡量业务数据的好坏。指标是一数值或者比例。
例如：好评量、好评率、增长率、销售额、利润额等。
维度: 维度是描述事情的角度，可以从不同维度分析同一指标，对指标进行细化。
例如：年份是时间维度，城市是地理维度等。

```

## 7.分组表/案例

分组表是FineBI中最基础的分析形式，本质就相当于SQL中的分组聚合操作，可以从不同维度对指标进行分析。

```properties
分组表分析流程：
    新建分析组件，选择数据源
    选择分组表，拖入维度和指标
    对分析结果或样式进行调整
```

## 9.可视化/案例

可视化分析是指用图形的方式来展示分析的结果，更有利于展示和读取结果中的有效信息。

| 图表目的 | 适合的图表类型                                               |
| -------- | ------------------------------------------------------------ |
| **比较** | **柱形图**、对比柱形图、分组柱形图、堆积柱形图、分区折线图、雷达图、**词云**、聚合气泡图、玫瑰图 |
| **占比** | **饼图**、矩形块图、百分比堆积柱形图、多层饼图、仪表盘       |
| **趋势** | **折线图**、范围面积图、面积图、散点图、瀑布图               |
| **分布** | **地图**、散点图、热力区域图、漏斗图                         |

```properties
可视化分析流程：
    新建分析组件，选择数据源
    先选择分组表，拖入维度和指标进行分析，然后切换为对应图表类型
    对分析结果或样式进行调整
```

## 10.钻取效果/案例

>实际业务往往比较复杂，一个组件的计算结果难以支撑分析结论。可能需要多个组件协作以读取重要信息。
>在实际使用仪表板时，往往会先通过统计图表从宏观层面把握业务问题所在，再通过一个页面内的钻取联动逐级向下钻取，直到明细数据，定位到具体的问题。

```properties
钻取可以让用户在查看仪表板时动态改变维度的层次，它包括向下钻取和向上钻取。
    下钻: 向下钻取：从宏观到细节。
    上卷: 向上钻取：从细节到宏观。
    
钻取流程：
    设置省市的地理角色，匹配经纬度
    创建钻取目录，加入省和市
    将钻取目录拖到图形的细粒度属性框
```
