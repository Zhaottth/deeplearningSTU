# AI 大模型开发学习记录

这个仓库用于记录 AI 大模型开发相关的学习内容与实践过程。学习范围从 **MySQL 数据库**开始，逐步延伸到数据处理、机器学习、深度学习、大模型应用、智能体开发，以及模型微调与部署。

目前以整理技术路线为主，后续会根据实际学习情况补充笔记、代码和项目。**下面列出的是计划接触的技术，不代表已经全部掌握。**

## 主要技术栈

| 方向 | 主要技术 | 学习内容 |
| --- | --- | --- |
| 数据库 | **MySQL、SQL、PyMySQL、Redis** | 数据库设计、增删改查、关联查询、数据操作与缓存 |
| 数据处理与可视化 | **NumPy、Pandas、Matplotlib** | 数组计算、数据清洗、统计分析与图表展示 |
| 机器学习 | **Scikit-learn** | 回归、分类、聚类、特征工程、模型评估与调参 |
| 深度学习 | **PyTorch** | 张量、自动微分、神经网络、CNN、RNN 和模型训练 |
| 自然语言处理 | **NLP、Transformer、BERT、GPT** | 文本表示、注意力机制、预训练模型与文本任务 |
| 大模型应用 | **Prompt Engineering、Coze、Dify、Ollama** | 提示词设计、工作流、模型调用与本地模型运行 |
| RAG 知识库 | **LangChain、Embedding、FAISS、Milvus** | 文档处理、向量检索、知识库问答与检索优化 |
| AI 智能体 | **LangGraph、Langfuse、MCP、A2A** | 工具调用、状态管理、多智能体协作与链路追踪 |
| 后端与工程化 | **FastAPI、Git、Docker、GitHub Actions** | API 开发、版本管理、容器化部署与自动化交付 |
| 模型微调与部署 | **Hugging Face、LoRA、QLoRA、DeepSpeed、GPTQ、vLLM** | 预训练模型使用、参数高效微调、量化和推理部署 |
| 进阶算法 | **模型蒸馏、RLHF、PPO、DPO、GRPO** | 模型压缩、偏好对齐与强化学习基础 |
| 计算机视觉与多模态 | **CNN、ResNet、YOLO、CLIP、Diffusion** | 图像处理、图像识别、目标检测与图文生成 |
